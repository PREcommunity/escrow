# Security policy

## Security status

`PREcommunityEscrowV1` has not undergone an independent security audit. The repository and its tests are provided for review and development; they are not a warranty, a mainnet-readiness declaration, or a guarantee concerning user funds.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability and do not include secrets, private keys, keystores, exploit transactions, or sensitive deployment details in public discussions.

Use GitHub's private vulnerability reporting flow instead:

1. Open the repository's **Security** tab.
2. Select **Advisories** and **Report a vulnerability**.
3. Include affected versions, impact, reproduction steps, and a minimal proof of concept when safe to share.

If the private reporting button is unavailable, wait for a maintainer to enable it before sharing sensitive details. Maintainers will acknowledge a complete report, coordinate remediation and disclosure privately, and credit reporters who want attribution.

The `0.1.x` development line is currently supported. No deployed address should be assumed supported or safe solely because its source matches this repository.
